# Documentation Gathering
* **Requirements Document:** Collect/locate business requirements documents 
* **Architecture Diagrams:** Collect high-level and detailed architecture diagrams.
    * Business architecture
    * Infrastructure architecture 
	* Solution architecture 
	* Data architecture
* **Design Documents:** Gather design specifications, API documentation, and data flow diagrams.
* **Interface documents:** Gather all the external interfacing systems, their interface docs, authentication mechanism, mode of communication, frequency of communication
* **Non-Functional Requirements (NFRs):** Obtain documentation on performance, scalability, security, and other NFRs.
* **Codebase and Repositories:** Access the source code and relevant repositories.
